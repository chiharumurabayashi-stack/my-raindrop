# MyRaindrop ユーザーガイド

MyRaindrop は、Firebase Firestore でブックマークを同期するオンライン専用の管理アプリです。現行アプリの入口は `index.html` です。

## はじめかた

1. インターネットに接続して、[MyRaindrop](https://chiharumurabayashi-stack.github.io/my-raindrop/) を開きます。
2. 「クラウドに同期済み」の表示を確認します。
3. 「+ 追加」から URL・タイトル・コレクション・タグを入力して保存します。

HTML ファイルを直接開く使い方や、オフライン起動は運用対象外です。ホーム画面に追加した場合も通信が必要です。

## 主な機能

- ブックマークの追加・編集・削除、タイトルとサムネイルの自動取得
- コレクション・タグによる整理、タイトル・URL・タグの検索
- ドラッグ＆ドロップによる並び替え、ピン留め、よく使うページへのアクセス
- Firebase Firestore による端末間の同期
- Gemini によるコレクション・タグ・要約の入力補助（設定で API キーを登録）
- JSON 形式のバックアップ・復元
- Chrome 拡張機能から閲覧中のページを保存

ページはサムネイルまたはタイトルをクリックして開きます。「開く」ボタンはありません。左上のつまみをドラッグすると、項目の間に青い挿入線が表示され、そこで離すと並び替えできます。

## 探し方と表示方法

初期画面は「すべて」です。以前のホームは廃止し、ピン留めしていたページは「お気に入り」に引き継いでいます。♡で追加・解除できます。お気に入りには件数上限や自動選出はなく、独立した並び順を保存します。

検索窓をクリックすると、お気に入り・タグ・コレクション・未分類・タグなしの絞り込みが表示されます。「タグ」を選ぶか `#` を入力すると、該当件数順の候補が出ます。続けて文字を入力するとタグ候補を絞れます。複数タグはすべてを含むものを表示し、文字検索（タイトル・URL・タグ・要約）とも組み合わせられます。選択した条件は検索窓の下の×で外せます。↑↓・Enter・Escでキーボード操作もできます。

一覧の右上から「リスト」「カード」「ヘッドライン」「ムードボード」を選べます。画像・タイトル・タグ・説明・URLの表示、リストの画像位置を調整できます。画像を隠す場合もタイトルのリンクは残ります。表示設定はコレクション・表示方法ごとにこのブラウザに保存され、「すべてに適用」でほかのコレクションと今後作るコレクションにも適用できます。表示設定は端末間では同期しません。

リストで説明を表示すると、広い画面ではタイトル・タグの右側に折り返して表示します。狭い画面では下に回り、説明を省略せずに読めます。

## コレクションとタグの使い分け

コレクションは「主な用途」、タグは「その中から探す手掛かり」で整理します。例えばメール・メモは「仕事・日常ツール」、銀行・決済は「お金・決済」、教材・研究資料は「学習・研究」にまとめます。読み返したい個別の記事は「保存した記事」を使います。

タグは通常0〜3個を目安に、RSS・画像編集・Blenderなど具体的な検索語を残します。`news` と「ニュース」のような表記違いは保存時に統一します。手動入力では必要な数だけ追加できます。

AI入力補助は既存コレクションと既存タグを優先します。新しい分類は「新しい候補（未適用）」に表示するので、必要なものだけ手動で追加してください。このルールはWeb版と拡張機能で共通です。

## 保存とバックアップ

ブックマークの同期先は Firebase Firestore です。ブラウザには、接続待ちの表示や保存失敗時の退避に使うデータの控えも保持します。この控えはオフライン起動や、未同期の編集の確実な復元を保証するものではありません。保存後は「クラウドに同期済み」の表示を確認してください。

- **JSON エクスポート**：ブックマークとコレクションをバックアップします。
- **JSON インポート**：読み込んだデータで置き換えてクラウドに保存します。他の端末にも反映されるため、必要に応じて先にエクスポートしてください。

現行版に Google Drive 連携はありません。サムネイル・ページ情報の取得では外部サービスへ URL を送り、AI 入力補助ではページ情報などを Gemini に送ります。

## Chrome 拡張機能

1. Chrome で `chrome://extensions/` を開き、デベロッパーモードをオンにします。
2. 「パッケージ化されていない拡張機能を読み込む」で `extension/` を選択します。
3. 保存したいページで拡張機能を開き、コレクション・タグを指定して保存します。新しいコレクションも作成できます。

拡張機能もオンライン接続が必要です。AI 入力補助の API キーは、Web アプリとは別に拡張機能側で設定します。

フォルダ内の拡張機能を更新した後は、拡張機能管理画面で MyRaindrop の再読み込みボタンを押してください。Braveでは `brave://extensions/` から同じ操作ができます。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | 現行オンライン版の画面・処理 |
| `library.js`・`browse.js`・`browse.css` | 検索条件・表示設定・一覧レイアウト |
| `extension/` | Chrome 拡張機能 |
| `manifest.json`・`icon.svg` | ホーム画面への追加用の設定・アイコン |
| `sw.js` | 旧バージョンのアプリ用キャッシュを削除する移行処理。キャッシュ配信は行わない |
| `my-raindrop-bookmarks.json` | エクスポート済みのバックアップ。自動更新されない |
| `SPEC.md` | 現行版の仕様 |
| `DESIGN.md` | 画面を変更する際のデザインルール |
| `my-raindrop.html` | 旧ローカル保存版の参考ファイル。現行オンライン版の入口ではない |

ビルド処理はありません。公開サイトへの反映には、変更ファイルを GitHub Pages の公開元へ反映する必要があります。

## 開発時の確認

Node.js がある環境では、`node --test tests/*.test.cjs` でカード操作と分類ルールのテストを実行できます。`node tests/preview.cjs` で [サンプルプレビュー](http://127.0.0.1:4179/) を起動できます。プレビューはサンプルデータだけを使用し、本番の Firebase には接続しません。
